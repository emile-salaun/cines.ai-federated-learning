## Going further { #going-further }

The papers behind the [Concepts](concepts.md) page.

**Algorithms and data**

- McMahan et al., *Communication-Efficient Learning of Deep Networks from Decentralized
  Data*, AISTATS 2017: [arXiv:1602.05629](https://arxiv.org/abs/1602.05629) (FedAvg)
- Li et al., *Federated Optimization in Heterogeneous Networks*, MLSys 2020:
  [arXiv:1812.06127](https://arxiv.org/abs/1812.06127) (FedProx)
- Hsu et al., *Measuring the Effects of Non-Identical Data Distribution for Federated
  Visual Classification*, 2019: [arXiv:1909.06335](https://arxiv.org/abs/1909.06335)
  (Dirichlet partitioning)

**Privacy**

- Bonawitz et al., *Practical Secure Aggregation for Privacy-Preserving Machine
  Learning*, CCS 2017: [Google Research](https://research.google/pubs/practical-secure-aggregation-for-privacy-preserving-machine-learning/)
- McMahan et al., *Learning Differentially Private Recurrent Language Models*, ICLR 2018:
  [arXiv:1710.06963](https://arxiv.org/abs/1710.06963)

**Deployments**

- Hard et al., *Federated Learning for Mobile Keyboard Prediction*, 2018:
  [arXiv:1811.03604](https://arxiv.org/abs/1811.03604)
- Dayan et al., *Federated learning for predicting clinical outcomes in patients with
  COVID-19*, Nature Medicine 2021: [doi:10.1038/s41591-021-01506-3](https://doi.org/10.1038/s41591-021-01506-3)
- Pati et al., *Federated learning enables big data for rare cancer boundary detection*,
  Nature Communications 2022: [doi:10.1038/s41467-022-33407-5](https://doi.org/10.1038/s41467-022-33407-5)
- Oldenhof et al., *Industry-Scale Orchestrated Federated Learning for Drug Discovery*
  (MELLODDY), 2022: [arXiv:2210.08871](https://arxiv.org/abs/2210.08871)

**FL on HPC**: see the [HPC context](demo.md#hpc-context) on the Demo page.
