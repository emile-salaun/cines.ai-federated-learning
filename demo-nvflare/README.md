# demo-nvflare

NVIDIA FLARE demo shown during the 15-minute demo slot: a federated job running across
two HPC centres (Adastra and a second centre), each site on its own SLURM reservation.
A recorded video is the backup.

The demo code, configuration and startup kits live in a separate private repository,
because they contain site-specific and sensitive details. Nothing from it is copied here.
